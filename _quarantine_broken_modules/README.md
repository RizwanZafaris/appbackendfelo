# Quarantined Kimi-generated modules

These modules were generated by the Kimi swarm but do not compile against
the current schema. They are kept here so future fix-ups can iterate on them
without polluting `main` builds.

`tsconfig.json` excludes this folder. App.module.ts no longer wires these in.

To re-enable a module:
1. Move it back to `src/modules/<name>/`
2. Reconcile schema references (familyId vs groupId, missing tables/types, etc.)
3. Add its module class back to `src/app.module.ts`
4. Run `npm run build` until clean before committing

Original imports were preserved in `src/app.module.ts` git history
(see fix/build-errors merge commit and feat/kimi-coverage-push original).
